## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "version": 1,
  "hooks": {
    "preToolUse": [{ "powershell": "./scripts/check.ps1" }]

}
```

### Valid

```json
{
  "version": 1,
  "hooks": {
    "preToolUse": [{ "bash": "./scripts/check.sh", "powershell": "./scripts/check.ps1" }]
  }
}
```
