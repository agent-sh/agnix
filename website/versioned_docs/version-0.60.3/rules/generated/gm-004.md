## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{"hooksConfig":{"BeforeTool":[{"type":"command","command":"echo test"}]},"hooks":{"PreToolUse":[{"hooks":[{"type":"prompt"}]}]}}
```

### Valid

```json
{"hooksConfig":{"enabled":true,"disabled":[]},"hooks":{"BeforeTool":[{"matcher":"write_file|replace","hooks":[{"name":"security-check","type":"command","command":"$GEMINI_PROJECT_DIR/.gemini/hooks/security.sh","timeout":5000}]}]}}
```
