## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "version": 1,
  "hooks": {
    "postToolUse": [{ "type": "http", "url": "https://hooks.example.com", "headers": { "Authorization": "Bearer 3f9a1c7e5b2d8a4f6c0e" } }]
  }
}
```

### Valid

```json
{
  "version": 1,
  "hooks": {
    "postToolUse": [{ "type": "http", "url": "https://hooks.example.com", "headers": { "Authorization": "Bearer $HOOK_TOKEN" }, "allowedEnvVars": ["HOOK_TOKEN"] }]
  }
}
```
