## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```markdown
jobs:
  copilot-setup-steps:
    runs-on: ubuntu-latest
    timeout-minutes: 90
    env:
      NODE_ENV: test
    steps:
      - run: npm ci
```

### Valid

```markdown
jobs:
  copilot-setup-steps:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    steps:
      - run: npm ci
        env:
          NODE_ENV: test
```
