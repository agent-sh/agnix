## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```markdown
---
description: Uses the issue tracker
mcp-servers:
  tracker:
    type: local
    command: tracker-mcp
    tools: ["list_issues"]
    env:
      TOKEN: ${{ secrets.TRACKER_TOKEN }}
---
Triage issues.
```

### Valid

```markdown
---
description: Uses the issue tracker
mcp-servers:
  tracker:
    type: local
    command: tracker-mcp
    tools: ["list_issues"]
    env:
      TOKEN: ${{ secrets.COPILOT_MCP_TRACKER_TOKEN }}
---
Triage issues.
```
