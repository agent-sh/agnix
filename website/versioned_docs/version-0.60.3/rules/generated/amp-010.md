## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "chrome-devtools": {
    "args": "-y chrome-devtools-mcp@latest",
    "includeTools": "navigate_*"
  }
}
```

### Valid

```json
{
  "chrome-devtools": {
    "command": "npx",
    "args": ["-y", "chrome-devtools-mcp@latest"],
    "includeTools": ["navigate_*", "take_screenshot"]
  }
}
```
