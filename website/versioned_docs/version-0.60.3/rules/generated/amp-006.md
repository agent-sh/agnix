## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "amp.mcpServers": {
    "internal-tools": {
      "command": "internal-mcp",
      "env": { "TOKEN": "${amp:id-token}" }
    }
  }
}
```

### Valid

```json
{
  "amp.mcpServers": {
    "internal-tools": {
      "url": "https://mcp.example.com/mcp",
      "headers": { "Authorization": "Bearer ${amp:id-token}" }
    }
  }
}
```
