## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "version": 1,
  "hooks": {
    "beforeShellExecution": [{ "type": "command", "command": "npm run lint", "timeout": "slow", "failClosed": "yes", "matcher": { "tool": "Shell" } }]
  }
}
```

### Valid

```json
{
  "version": 1,
  "hooks": {
    "beforeShellExecution": [{ "type": "command", "command": "npm run lint", "timeout": 30, "failClosed": true, "matcher": "npm|pnpm" }]
  }
}
```
