## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "mcpServers": {
    "my-server": {
      "type": "websocket",
      "url": "ws://localhost:8080"
    }
  }
}
```

### Valid

```json
{
  "mcpServers": {
    "my-server": {
      "type": "stdio",
      "command": "node"
    }
  }
}
```
