## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```markdown
---
name: linear
description: Manages Linear issues. Use when filing or updating an issue.
mcpServers:
  linear:
    url: https://mcp.linear.app/mcp
---

Use the linear tools.

(A sibling mcp.json also defines servers; Amp ignores it.)
```

### Valid

```markdown
---
name: linear
description: Manages Linear issues. Use when filing or updating an issue.
mcpServers:
  linear:
    url: https://mcp.linear.app/mcp
    includeTools: [list_issues]
---

Use the linear tools.

(No sibling mcp.json.)
```
