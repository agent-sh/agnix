## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "version": 1,
  "hooks": { "sessionStart": [{ "command": ".cursor/hooks/init.sh" }] }
}
(project with .cursor/environment.json)
```

### Valid

```json
{
  "version": 1,
  "hooks": { "afterFileEdit": [{ "command": ".cursor/hooks/format.sh" }] }
}
```
