## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "version": 1,
  "hooks": {
    "preToolUse": [{ "type": "http", "url": "http://hooks.example.com/check" }],
    "postToolUse": [{ "bash": "./audit.sh", "matcher": "*" }]
  }
}
```

### Valid

```json
{
  "version": 1,
  "hooks": {
    "preToolUse": [{ "type": "http", "url": "https://hooks.example.com/check" }],
    "postToolUse": [{ "bash": "./audit.sh", "matcher": "bash|edit" }]
  }
}
```
