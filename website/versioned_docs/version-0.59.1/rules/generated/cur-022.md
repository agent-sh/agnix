## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "version": 1,
  "hooks": { "afterFileEdit": [{ "command": "./hooks/format.sh" }] }
}
(.cursor/hooks.json in a project; the script is .cursor/hooks/format.sh)
```

### Valid

```json
{
  "version": 1,
  "hooks": { "afterFileEdit": [{ "command": ".cursor/hooks/format.sh" }] }
}
```
