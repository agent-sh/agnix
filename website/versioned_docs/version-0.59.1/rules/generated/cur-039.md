## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  // allow git
  "permissions": { "allow": ["Bash(git)"], "deny": "Shell(rm)" }
}
```

### Valid

```json
{
  "version": 1,
  "permissions": { "allow": ["Shell(git)"], "deny": ["Shell(rm)"] }
}
```
