## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "version": 1,
  "hooks": {
    "beforeTool": [{ "command": { "bash": "./scripts/check.sh" } }]
  }
}
```

### Valid

```json
{
  "version": 1,
  "hooks": {
    "preToolUse": [{ "type": "command", "bash": "./scripts/check.sh", "timeoutSec": 10 }]
  }
}
```
