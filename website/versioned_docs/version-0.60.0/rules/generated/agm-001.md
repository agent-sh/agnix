## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

````markdown
# Project

```python
def hello():
    print("world")

This code block is never closed.
````

### Valid

````markdown
# Project

```python
def hello():
    print("world")
```

See [docs](https://example.com) for more.
````
