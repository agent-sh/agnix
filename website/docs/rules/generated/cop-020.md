## Examples

The following examples demonstrate what triggers this rule and how to fix it.

### Invalid

```json
{
  "name": "my-dev-tools",
  "keywords": "react",
  "skills": {}
}
```

### Valid

```json
{
  "name": "my-dev-tools",
  "keywords": ["react"],
  "skills": ["skills/", "extra-skills/"]
}
```
