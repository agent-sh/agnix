### Notable changes per version

**3.0 ("New Cursor Interface") - 2026-04-02**

Feature-level changes (no config format impact):

- New Agents Window: run agents in parallel locally, in worktrees, in the cloud, and on remote SSH
- /worktree command: creates a git worktree for isolated changes
- /best-of-n command: parallel runs across multiple models in isolated worktrees
- Design Mode for annotating browser UI elements
- Agent Tabs in the Editor
- Deprecated old worktree/best-of-n selection from Editor; removed cloud agents from Editor
- MCP Apps now support structured content
- Enterprise Admin control to disable "Made with Cursor" attribution
- Added Await tool so agents wait on background shell commands and subagents
- Fixed hooks loading: multi-root workspaces now read hook files from ALL workspace folders (not just first). Bug fix, no schema change.

**04-08-26 ("Bugbot Learned Rules and MCP Support") - 2026-04-08**

- Bugbot can learn from PR feedback (cloud-side learned rules; no new local .cursor/ config)
- Bugbot MCP Support (cloud feature via Bugbot dashboard; no new local file)
- Bugbot resolution rate 78%, Autofix only runs on substantial findings

**3.1 ("Tiled Layout and Upgraded Voice Input") - 2026-04-13**

Feature-level changes (no config format impact):

- Tiled layout in Agents Window (split view into panes)
- Upgraded voice input (press and hold)
- Branch selection in empty state for cloud agents
- Diff-to-file navigation
- Include/exclude filters in file search
- Performance: instant follow-up in long chats, large edit streaming improved ~87%
- Fixed scrolling stutter in long conversations

**04-15-26 ("Canvases") - 2026-04-15**

- Cursor can now respond by creating interactive canvases (tables, boxes, diagrams, charts)
- Available in Agents Window in Cursor 3.1; no local config impact

## Risks and uncertainties

1. Cursor docs URL migration is the biggest risk. The /docs/context/rules 404 is confirmed. The new URL is inferred from the /docs/context/subagents -> /docs/subagents redirect pattern. If the rules URL moved differently (e.g., /docs/context/cursor-rules), the PR would record a wrong URL. Mitigation: verify in browser before merging.
2. Pre-3.0 patches not covered. Version scheme jumped from 0.x to 3.0.0; no 0.x patches need review. Confirmed by Wayback CDX: only changelog/3-0 and changelog/3-1 exist as named version pages.
3. JS-rendered docs prevent direct schema inspection. This triage verifies no schema changes by the absence of changelog mentions, not by direct docs page reading. An undocumented optional field added to cursor rules without a changelog entry would be missed.
