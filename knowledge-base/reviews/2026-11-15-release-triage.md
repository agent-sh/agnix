Issues #1827 (Claude Code), #1828 (Cursor), #1829 (Kimi Code), #1830
(Kiro CLI), #1842 (Antigravity CLI), #1844 (OpenCode 2), #1845 (spec
drift, Claude Code docs) and #1846 (Codex CLI) were reviewed against the
live vendor sources, not just the watcher's quoted markers. The
read-only release poll (`UPDATE_BASELINES=true bash
scripts/check-tool-releases.sh`) reports `ok=7 new=7 skipped=1 errors=0`
before the advance: antigravity 1.5.9, claude-code v2.1.325, codex
rust-v0.169.0, cursor 3.30.14, kimi-code @moonshot-ai/kimi-code@2.6.2,
kiro 3.3.0 and opencode-v2 v2.3.0. Baselines advance to the live
markers, which cover and exceed the versions the issues quote (Claude
Code v2.1.323 - there is no v2.1.324 release; Kimi Code 2.6.1; Cursor
3.30.8).
